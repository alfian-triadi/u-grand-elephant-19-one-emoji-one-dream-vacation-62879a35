One emoji, one dream vacation: a desert island — palm tree, sand, and nobody else on the calendar. It is the faraway escape in a single glyph: no meetings, no notifications, just an island that fits in your pocket until you can actually book the trip.

## Run it

```sh
node main.ts
```

This writes exactly one emoji to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
